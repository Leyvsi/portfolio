# Les Petits Enquêteurs — Frontend autonome

## Démarrage

1. Décompresser le ZIP.
2. Ouvrir `index.html` dans Chrome ou Safari (double-clic).
3. Naviguer entre les pages.

**Aucune installation Python, Flask, SQLAlchemy ou base de données n’est nécessaire.**

## Contenu

- `index.html` : accueil
- `histoires.html` : 3 histoires originales
- `coldcases.html` : 3 Cold Cases originaux
- `dossier.html` : fiche de dossier avec résumé
- `theories.html` : espace analyse, maquette
- `connexion.html`, `inscription.html`, `admin-connexion.html` : formulaires de démonstration
- `admin-dashboard.html` : maquette d’administration
- `proposer-histoire.html` : formulaire de démonstration
- `styles.css` : styles responsives
- `donnees.js` : données des 6 histoires récupérées du ZIP original
- `app.js` : affichage, recherche et interactions locales
- `histoires-originales.json` : copie structurée des titres et résumés d’origine

## Important

Les titres et résumés des six histoires sont repris du projet initial `portfolio-main (3)(1).zip`. Les textes longs d’origine et leurs galeries d’images ne sont **pas** inclus dans cette version légère ; ils pourront être ajoutés ultérieurement. Les formulaires ne créent pas de compte et n’enregistrent aucune information. L’administration n’est pas protégée : c’est une maquette, pas un véritable espace privé. Aucun appel réseau/API (`fetch`) n’est effectué.
